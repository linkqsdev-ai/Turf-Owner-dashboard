# Tech Stack

## Frontend
- **Framework:** Next.js (React)
  - *What:* A powerful React framework for production.
  - *Why:* Provides Server-Side Rendering (SSR) out of the box, excellent SEO benefits, and optimized page load performance.
- **Language:** TypeScript
  - *What:* Strongly typed JavaScript.
  - *Why:* Dramatically reduces runtime errors and improves the developer experience with robust IDE support.
- **Styling:** Tailwind CSS
  - *What:* Utility-first CSS framework.
  - *Why:* Enables rapid UI development while strictly adhering to design tokens and typography rules.
- **Components:** Shadcn UI
  - *What:* Beautifully designed, accessible, and customizable component system.
  - *Why:* Accelerates development of premium UI elements without the bloat of traditional component libraries.
- **Charts:** Recharts
  - *What:* Composable charting library built on React components.
  - *Why:* Easy integration and highly responsive data visualization for analytics.

## Backend
- **Framework:** NestJS / Node.js
  - *What:* A progressive Node.js framework.
  - *Why:* Enforces a modular, scalable, and highly maintainable enterprise-grade architecture.
- **Language:** TypeScript
  - *What:* Strongly typed backend code.
  - *Why:* Allows sharing of data types between frontend and backend, reducing integration bugs.
- **Database:** PostgreSQL
  - *What:* Advanced open-source relational database.
  - *Why:* Provides ACID compliance, robust relational data handling, and high performance for scaling.

## Tooling & CI/CD
- **Code Quality:** Prettier, ESLint, SonarQube
  - *What:* Linters and static code analysis tools.
  - *Why:* Enforces strict coding standards, auto-formats code, and detects security vulnerabilities/bugs early in the pipeline.
